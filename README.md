# Sistema de Aquisição e Monitorização de Sensores

Na UC de Programação, cada grupo de quatro alunos irá, ao longo do semestre, desenvolver um sistema de aquisição, calibração e análise de dados provenientes de sensores.

O projeto evoluirá através da publicação de novas especificações
("sprints") ao longo do semestre. Todas as especificações oficiais serão divulgadas neste repositório.

Os grupos deverão a cada semana consultar as especificações que tenham sido lançadas para conhecer as nossas características a adicionar ao programa.
