# Sistema de Aquisição e Monitorização de Sensores

Ao longo do semestre cada grupo irá desenvolver um sistema de aquisição,
calibração e análise de dados provenientes de sensores.

O projeto evoluirá através da publicação de novas especificações
("sprints") ao longo do semestre.

Todas as especificações oficiais serão divulgadas neste repositório.
